# Names of values that are safe to log without a redaction tag wherever they appear.
#
# A name belongs here only if every value it holds, anywhere in the SDK, is something the SDK
# generated or a protocol constant: it reads the same for every deployment and identifies nobody.
# Matching is by exact name, with no regard to type or scope: the variable, the field
# (`self.pool_id` matches `pool_id`) or the method (`client.pool_id()` matches `pool_id`). If a
# name is only safe in some places, leave it off and mark those call sites with not_sensitive()
# instead.
#
# So a name that is safe in most places but not all stays off. `id` is one: it is a generated UUID
# on SDK components, but the `couchbase` crate also uses it for document keys, and an HTTP request
# id can be set by the caller. `reason` is another: it is an enum on retries, but server response
# text on management errors.
